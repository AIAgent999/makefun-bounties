# Zoostr Logo — "The Hearth Arch"

Entry for POIDH bounty #582 (Base) — *"Design the Zoostr logo. Best one wins."*
Bounty: https://poidh.xyz/base/bounty/1568

## Concept

Zoostr is a **Creator Hearth** — so the mark is a hearth: a rounded arch,
the oldest symbol of a gathering place, filled with a vertical ember
gradient (gold → amber → burnt orange, the colours of firelight).

- **The Z** is cut out of the arch in true negative space — the fire inside
  the hearth is shaped like Zoostr's initial. In the SVG it is a real
  cutout (mask), so the mark sits correctly on any dark surface.
- **The spark** above the arch is a nod to Sparkz, the platform Zoostr
  launched through: every hearth starts with a spark, and this one is
  already lit.
- **The wordmark** is lowercase and warm — `z**oo**str` — with the double-o
  set in the same ember gradient as the mark: the two round "windows" of
  the hearth, glowing.

It reads at favicon size (bold silhouette, one idea) and stays friendly
rather than corporate — a community hearth, not a bank.
